# Additional field module

Модуль предоставляет возможность делать кастомные константы которые потом будут доступны по всему сайту.

В ходе данной работы необходимо выполнить следующие задачи:

- Сделать корректный вывод всех константных переменных. На данный момент twig переменные не работают, также проверь php вывод переменных;
- Ожидается такой формат использования переменных <?php print_field_info("variable_name"); ?> и для Twig {{variable_name}}
- Ожидаются логические проверки наличия значения в переменных и вывод соответствующих сообщений например: "Переменная не заполнена!" при выводе переменных, значения которых пусты;
- Не менять путь к настройкам и расположение в меню (/admin/config/system/additional-field, Главная-Администрирование-Конфигурация-Система-Дополнительные поля);
- Сделать более удобные настройки, разделённые на несколько частей
  * Основная форма, которая содержит поля: 
    * Номер телефона, 
    * Адрес электронной почты, 
    * Режим работы, 
    * Адрес компании, 
    * Код Яндекс карты (iframe или script)
    * Дополнительное поле "Дополнительная информация" textarea
  * Вторичная форма, которая содержит поле-таблицу, где я смогу указать социальные сети, по умолчанию строк не должно быть, а только кнопка "Создать", после нажатия на которую появится строка с полями для названия переменной и значения переменной. добавление строк должно работать без перезагрузки страницы.
  * Третья форма, которая содержит поле-таблицу как во вторичной форме только для произвольных переменных. добавление строк должно работать без перезагрузки страницы.
- Система должна быть целостной, в одном стиле, без невнятных и непонятных полей;
- Сделать только то, что нужно;
- Провести проверку синтаксиса;
- Все константные переменные должны быть доступны на любой странице, в любом блоке, материале или поле. Также должны быть доступны в полях и отображении Display suite.
