## Проверенные критерии

- `print_field_info("variable_name")` печатает экранированное значение или понятное диагностическое сообщение.
- Twig extension предоставляет фиксированные и динамические переменные под их machine names.
- Пустое значение представляется сообщением `Переменная не заполнена!`.
- Административный route и menu parent не изменены.
- Основные, социальные и произвольные настройки разделены на три секции.
- Обе таблицы стартуют без строк; кнопка `Создать` добавляет строку через Form API AJAX.
- Конфигурация имеет schema/default config и validation уникальных machine names.
- Манифест совместим с Drupal 10/11 и сохраняет dependency `vesta_core`.
- Яндекс embed ограничен HTTPS iframe/map-widget и script/services/constructor на разрешённых доменах.
